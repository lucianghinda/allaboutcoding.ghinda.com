{% comment %} Two related articles at the end of a post. The ranking comes from _data/related_posts.yml, precomputed by bin/compute_related_posts.rb with latent semantic indexing. Jekyll can do this during the build with `--lsi`, but that is a sixteen minute single-threaded SVD on this site, and the deploy workflow rebuilds on every push. So the slow part runs locally and the result is committed. Only URLs are stored, and the post is looked up here, so titles and dates stay correct after an edit. A post missing from the data file (just published, script not rerun yet) renders nothing. Styled as a tinted block on purpose: it sits after the article and must not read as one more paragraph of it. {% endcomment %} {% assign related_urls = site.data.related_posts[page.url] %} {% if related_urls %} {%- assign shown = 0 -%} {%- capture related_items -%} {%- for url in related_urls -%} {%- if shown >= 2 -%}{%- break -%}{%- endif -%} {%- assign item = site.posts | where: "url", url | first -%} {%- if item -%} {%- assign shown = shown | plus: 1 %}
