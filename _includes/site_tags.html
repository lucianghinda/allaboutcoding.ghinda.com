{% comment %} Site-wide tag index. Shown at the bottom of the home page only. There are ~120 tags across ~110 posts and two thirds of them have a single post, so listing all of them buried the handful people actually browse. The most-used tags are shown first with their post counts; the long tail sits behind a toggle, alphabetically. Liquid cannot sort a hash by its values, so each tag is folded into a zero-padded string ("092|ruby") that sorts lexicographically by count, then split back apart. Padding to 3 digits caps this at 999 posts per tag. {% endcomment %} {% assign top_tags_shown = 12 %} {%- capture tag_entries -%} {%- for tag in site.tags -%}{{ tag[1].size | prepend: "000" | slice: -3, 3 }}|{{ tag[0] }},{%- endfor -%} {%- endcapture -%} {%- assign ranked_tags = tag_entries | split: "," | sort | reverse -%} {%- comment -%} Delimited list of the shown names, so the toggle can skip them. {%- endcomment -%} {%- capture top_tag_names -%} {%- for entry in ranked_tags limit: top_tags_shown -%}|{{ entry | split: "|" | last }}{%- endfor -%}| {%- endcapture -%}
