{% comment %} Newsletter invite. Rendered once on the home page and once after each article, from the `newsletter:` block in _config.yml. Plain GET form on purpose. The site ships no JavaScript beyond the theme toggle, and a provider iframe would be the only element on the page that cannot follow the dark theme. So the form just hands the address to beehiiv as a query parameter and lets the reader confirm there (beehiiv uses double opt-in anyway, so nothing is saved on submit either way). If beehiiv ever stops prefilling, the reader still lands on the subscribe page and types the address — the worst case is one extra keystroke set, not a dead button. Two visual notes, both about sitting next to related_posts.html at the end of a post: this one is lighter than the page (bg-stone-50) where "Read next" is darker (bg-stone-200/70), so the two blocks read as different things rather than one long tinted slab. The amber left edge is the same accent the nav and TOC links use on hover — the one place the site allows color. Uses a fixed element id, so include it at most once per page.
